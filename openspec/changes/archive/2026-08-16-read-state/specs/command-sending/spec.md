## ADDED Requirements

### Requirement: Запрос состояния блока nooLite-F

Библиотека SHALL предоставлять операцию запроса состояния блока в режиме nooLite-F
с командой `Read_State` (128) в двух формах:

- **по каналу** — обычная передача (действие «передать команду», CTR=0), на неё отвечает
  каждый привязанный к каналу блок собственным пакетом `Send_State`;
- **адресно** — передача по 32-битному ID блока (действие «передать по указанному ID», CTR=8),
  отвечает только этот блок.

Формат данных пакета SHALL задавать адрес строки таблицы состояния; по умолчанию — 0
(основная информация: тип, версия, состояние, мощность).

#### Scenario: Запрос по каналу

- **WHEN** потребитель запрашивает состояние канала 0 без указания ID
- **THEN** в порт уходит пакет с режимом TXF, действием CTR=0, каналом 0, командой 128 и FMT 0
- **AND** от каждого привязанного к каналу блока приходит свой `Send_State`

#### Scenario: Адресный запрос

- **WHEN** потребитель запрашивает состояние блока с ID 33347 на канале 0
- **THEN** в порт уходит пакет с режимом TXF, действием CTR=8, каналом 0, командой 128, FMT 0
  и адресом устройства 33347
- **AND** приходит `Send_State` только от этого блока

#### Scenario: Запрос другой строки таблицы

- **WHEN** потребитель запрашивает состояние с адресом строки, отличным от 0
- **THEN** в поле формата данных пакета уходит указанный адрес
- **AND** если блок такой строки не знает — приходит `Send_State` с форматом 255
